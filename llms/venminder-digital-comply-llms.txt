# Venminder (Digital Comply)

> Venminder is a third-party risk management (TPRM) platform — vendor onboarding, due diligence, contract tracking, questionnaires, oversight and continuous monitoring for financial institutions. Founded as Digital Comply, backed by Bain Capital Ventures, and merged with Ncontracts in 2024. The Venminder API (OAuth 2.0 client credentials, scope venminderApi) exposes a customer's vendors, products, contracts, documents, questionnaires, onboarding, oversight, issues, spend and Venmonitor scores at https://rsd.venminder.com; users are provisioned via a SCIM 2.0 surface at /scim/v2.

## APIs

- [Venminder API developer portal](https://developers.venminder.com/): getting started, API key setup, endpoint reference
- [OpenAPI (Swagger UI)](https://rsd.venminder.com/swagger): live schema for the v1 endpoints
- [OpenAPI JSON](https://rsd.venminder.com/swagger/v1/swagger.json): 57 operations across Vendors, Contracts, Documents, Questionnaire, Vendor Onboarding, Oversight, Issues, Spend Analysis, Services, Venmonitor
- [Token endpoint](https://login.venminder.com/connect/token): OAuth 2.0 client-credentials grant, scope venminderApi
- [OIDC discovery](https://login.venminder.com/.well-known/openid-configuration): IdentityServer discovery document
- SCIM 2.0 user provisioning: https://rsd.venminder.com/scim/v2/Users (core:2.0:User + extension:Venminder:2.0:User)
